# pxie

> [!WARNING]
> This library is still under early development.

Pxie aims to be a simple software for pixel art.

Roadmap:
- [x] Draw a grid on screen.
- [ ] Draw a color picker on screen.
- [x] Paint grid cells with the selected color on user click.
- [x] Save art to PNG.
- [ ] Save and open the art state to a .pxie file.

# Dependencies

- [parsec](github.com/kerudev/parsec): my C argument parser.
- [raylib](https://github.com/raysan5/raylib): raylib.h, rlgl.h and raymath.h
- [stb_image.h](https://github.com/nothings/stb/blob/master/stb_image.h)
- [stb_image_write.h](https://github.com/nothings/stb/blob/master/stb_image_write.h)
